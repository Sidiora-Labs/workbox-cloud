# Next.js Blog

Publish a Markdown blog from the official Next.js example.

Choose **Vercel project**, select a saved Vercel account and give the installation a new project name. Review and deploy without leaving Workbox Cloud. The installation manages the created Vercel project and deployment, including status, build logs and confirmed project deletion.

The source is [vercel/next.js](https://github.com/vercel/next.js/tree/ad4859b599128915430ab68bcf344bddf81c0177/examples/blog-starter) at revision `ad4859b599128915430ab68bcf344bddf81c0177` under MIT. No database, storage service or repository clone is created. Your Vercel account must be allowed to deploy this public repository. This recipe is a web application deployment, not a long-running container or sandbox.

Source: [Vercel template listing](https://vercel.com/templates/next.js/blog-starter-kit). Provider deployment has not been live-qualified until the installation receipt records a successful build and readiness result.

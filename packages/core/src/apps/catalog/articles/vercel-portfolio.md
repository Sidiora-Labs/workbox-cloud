# Portfolio Starter

A portfolio and MDX blog with SEO, RSS and generated social images.

Choose **Vercel project**, select a saved Vercel account and give the installation a new project name. Review and deploy without leaving Workbox Cloud. The installation manages the created Vercel project and deployment, including status, build logs and confirmed project deletion.

The source is [vercel/examples](https://github.com/vercel/examples/tree/a4b4827297bec79b81ddb2ff22a53089ebe88cd8/solutions/blog) at revision `a4b4827297bec79b81ddb2ff22a53089ebe88cd8` under MIT. No database, storage service or repository clone is created. Your Vercel account must be allowed to deploy this public repository. This recipe is a web application deployment, not a long-running container or sandbox.

Source: [Vercel template listing](https://vercel.com/templates/template/portfolio-starter-kit). Provider deployment has not been live-qualified until the installation receipt records a successful build and readiness result.
